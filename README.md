# 🛒 Catálogo Pro | Proyecto Final Master of Coding

¡Bienvenido a mi Proyecto Final! Esta es una aplicación de catálogo interactivo desarrollada con el stack moderno de React.

## 🚀 Vista Previa
La aplicación está desplegada en: **[Ver Proyecto en Vercel](https://github.com/melspaceux/MOD-8-PRO-FINAL.2)** *(Enlace al repo mientras se activa el despliegue)*

## ✨ Características Principales
- **Catálogo Dinámico:** Consumo de datos reales desde Fake Store API.
- **Buscador Inteligente:** Filtrado de productos en tiempo real.
- **Detalles de Producto:** Vista expandida con descripción y valoraciones.
- **Carrito de Compras:** Gestión completa de productos y persistencia en LocalStorage.
- **Autenticación:** Sistema de login seguro con JWT (simulado con API real).
- **Rutas Privadas:** Protección de información sensible (Perfil de Usuario).
- **Diseño Premium:** Interfaz moderna, responsiva y con soporte para modo oscuro.

## 🛠️ Tecnologías Utilizadas
- **Core:** React 18 + Vite
- **Navegación:** React Router Dom v6
- **Estado Global:** Context API
- **Validaciones:** Zod + React Hook Form
- **Comunicación:** Axios
- **Optimización:** React.memo, useMemo, useCallback, Lazy Loading + Suspense
- **Despliegue:** Vercel
- **CI/CD:** GitHub Actions

## 📂 Estructura del Proyecto
- `src/assets/`: Recursos estáticos.
- `src/components/`: Componentes reutilizables y atómicos.
- `src/context/`: Lógica de estado global (Auth y Cart).
- `src/hooks/`: Hooks personalizados.
- `src/pages/`: Vistas principales de la aplicación.
- `src/services/`: Configuración de API y servicios externos.
- `.github/workflows/`: Automatización de Integración Continua.
